# Codex — Degenerate Earth

This repository is the source for **codex.degenerate.earth** (GitHub Pages).

## Site structure

- `index.html` — public-facing interactive introduction
- `styles.css` — complete visual system and responsive layout
- `script.js` — arithmetic lesson, navigation, and subtle motion
- `assets/codex-*.jpg` — web review renders of the four-face prototype
- Markdown folders — deeper research, canon, and archive pages

## Quick edit workflow

- Edit the homepage files or Markdown research pages.
- Commit to `main`.
- GitHub Pages will redeploy automatically.

## Structure

- `archive/original-homepage.md` — retained source text from the original homepage
- `canon/` — brand canon
- `obelisk/` — Obelisk project docs
- `design/` — symbols / iconography
- `archive/` — raw notes
- `assets/` — images and other static files

## Current prototype

The September 2026 update records the first complete four-face Obelisk model: 18 panels and 57 illustrated lesson rows covering arithmetic, geometry, physics, and chemistry. The public site presents web-optimized review images; editable 3D, vector, and audit artifacts are maintained with the offline project package.
